# Soumith Reddy Chinthalapally — portfolio

Static, responsive portfolio with dark and light themes and native expandable case studies.

Open `dist/index.html` directly for a local preview, or serve the `dist` directory using any static web server. No installation or build is required.

- `dist/index.html`: content and semantic structure
- `dist/styles.css`: responsive layout and both theme palettes
- `dist/script.js`: system preference and persisted theme switching
- `.openai/hosting.json`: Sites identity and static output configuration

Only supplied GitHub and LinkedIn contact links are included. Credentials are described by earned date. The systems diagram is conceptual.

Validation: JavaScript syntax; unique IDs; internal navigation anchors; asset references; theme initialization, toggling, persistence, OS changes, and unavailable storage. Browser visual QA is not included in those checks.
